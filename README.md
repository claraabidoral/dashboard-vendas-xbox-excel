# dashboard-vendas-xbox-excel
Dashboard desenvolvido em Excel para análise e visualização dos dados de vendas e assinaturas do Xbox Game Pass.
# Dashboard de Vendas do Xbox com Excel

Projeto desenvolvido para o desafio **Criando um Dashboard de Vendas do Xbox com Excel**, utilizando a base de dados disponibilizada no curso da DIO.

## Objetivo

O objetivo deste projeto é transformar dados brutos de vendas e assinaturas do Xbox Game Pass em informações visuais claras e úteis.

O dashboard permite analisar o desempenho das vendas, identificar os planos mais relevantes e visualizar informações que auxiliam na tomada de decisões baseada em dados.

##  Base de Dados

A base utilizada no projeto contém **295 assinantes** e informações como:

- ID do assinante;
- Nome do assinante;
- Plano contratado;
- Data de início da assinatura;
- Renovação automática;
- Preço da assinatura;
- Tipo de assinatura;
- EA Play Season Pass;
- Minecraft Season Pass;
- Cupons utilizados;
- Valor total da venda.

##  Indicadores do Dashboard

O dashboard apresenta os principais indicadores da base:

- **Faturamento total:** $7.633;
- **Total de assinantes:** 295;
- **Ticket médio:** aproximadamente $25,87;
- Quantidade de assinantes com EA Play;
- Faturamento por plano;
- Faturamento por tipo de assinatura;
- Faturamento por renovação automática;
- Quantidade de assinantes por plano.

##  Análise dos Planos

Foram analisados os três planos disponíveis na base:

- Core;
- Standard;
- Ultimate.

O dashboard permite comparar o faturamento e a quantidade de assinantes de cada plano.

##  Renovação Automática

Também foi realizada uma análise dos clientes que possuem ou não renovação automática.

Isso permite visualizar a participação de cada grupo no faturamento total e compreender melhor o comportamento das assinaturas.

##  Planos Anuais

Uma das análises realizadas foi sobre os planos anuais.

Os resultados encontrados foram:

- **Faturamento dos planos anuais:** $1.754;
- **Com renovação automática:** $1.537;
- **Sem renovação automática:** $217;
- Aproximadamente **87,6%** do faturamento dos planos anuais corresponde a assinaturas com renovação automática.

##  Recursos Utilizados

Durante o desenvolvimento foram utilizados recursos do Excel como:

- SOMA;
- SOMASE;
- SOMASES;
- CONT.SE;
- Tabelas auxiliares;
- Indicadores de desempenho (KPIs);
- Gráficos;
- Formatação e organização visual dos dados.

##  Estrutura do Arquivo

O arquivo Excel foi organizado em três áreas principais:

### Bases
Contém os dados originais disponibilizados para realização do desafio.

### Calculos
Contém as fórmulas, indicadores e tabelas auxiliares utilizadas para transformar os dados brutos em informações.

### Dashboard
Apresenta os principais indicadores e gráficos de forma visual e organizada.

##  Como Utilizar

1. Faça o download do arquivo Excel disponível neste repositório.
2. Abra o arquivo no Microsoft Excel.
3. Consulte a aba **Bases** para visualizar os dados utilizados.
4. Acesse **Calculos** para conferir as análises realizadas.
5. Abra a aba **Dashboard** para visualizar os indicadores e gráficos finais.

## Resultado

O resultado final é um dashboard capaz de transformar a base de vendas do Xbox Game Pass em informações de fácil interpretação, permitindo analisar faturamento, assinantes, planos e características das assinaturas.

> Projeto desenvolvido para fins educacionais como parte de um desafio da DIO.
